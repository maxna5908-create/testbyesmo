# Первичный опросник

Источник: «001 BYESMO - первичный - опросник.xlsx», лист 01_Первичный_опросник,
Q01–Q15, семь групп из колонки A. Слайды открываются до первого входа в опросник.
После нажатия «Начать» открывается опрос. При повторном запуске после заставки
восстанавливается черновик или итоговая сводка. Есть назад/далее, верхний прогресс,
проверка обязательных полей, финальная страница всех 15 ответов и их редактирование.

## Правила

- Возраст: 1–120; сигарет в день и пачке: 1–200. Цена: >0 до 1000000,
  до двух десятичных знаков, отдельный код валюты (по умолчанию RUB).
- Q02 влияет только на будущий аватар, в вычислениях не используется.
- Пересечения Q03 устранены: 1, 2–3, 4–5, 6–10, 11–15, 16–20, >20 лет.
- Q06 показывается только при Q05 >1; использованы четыре частотных варианта
  исходника, формулировка уточнена для двух и трёх сигарет.
- Q09 по умолчанию 07:00–23:00, поддерживает ночной режим. Равные времена запрещены.
- Q10: сразу, 1–5, 6–15, 16–30, 31–60 минут, более часа (устранены пересечения).
- Q11 по умолчанию равномерно; Q12 нужен только для выбранной части дня.
- Q14 ограничен категорией Q13; «Ни разу» устанавливает нулевые попытки за год.
- Q15: сейчас, завтра с выбором времени, произвольная прошедшая/будущая дата и
  время, либо определюсь позже. Время хранится как epoch milliseconds. Для
  «Определюсь позже» временная метка отсутствует, счётчик запускать нельзя.

## Хранилище и обновления

Room/SQLite, внутренняя база byesmo.db, таблица assessment_session. Одна первичная
сессия: стабильный id, версия опросника, JSON ответов по стабильным Q01–Q15,
текущая страница, completed, updatedAt. Дополнительные ключи: currency, wake,
sleep, quitInstant. Каждый снимок записывается атомарным Upsert. Записи черновика
выполняются последовательно вне UI-потока через Room; ошибки видны на экране и
не подменяются сообщением об успешном сохранении. При ошибке чтения база не
сбрасывается. Скрываемые Q06/Q12 и ненужная дата удаляются при смене ответа.

Схема Room v1 экспортируется в app/schemas. При будущих изменениях обязательны
миграции с тестами сохранности; запрещён fallbackToDestructiveMigration.
Не менять applicationId и ключ подписи при обновлениях, увеличивать versionCode.
Сетевой синхронизации нет. Android cloud backup и device transfer исключены.
Удаление приложения/очистка данных удаляют базу; экспорт в этой версии не реализован.
